# Сервис управления рассылками (Mailing Service)

Веб-приложение на Django для автоматизации и управления рассылками сообщений клиентам. Проект содержит полноценную реализацию CRUD для управления клиентами, сообщениями и рассылками, динамический расчет статусов, логирование попыток отправки, а также разграничение прав доступа (пользователь/менеджер) и кэширование данных.

## 🚀 Основной функционал

### Часть 1. Разработка сервиса
* **Управление клиентами (CRUD):** Создание, просмотр, редактирование и удаление получателей рассылок (ФИО, Email, комментарий).
* **Управление сообщениями (CRUD):** Создание шаблонов писем (Тема и Тело письма).
* **Управление рассылками (CRUD):** Настройка временных диапазонов (`start_time`, `end_time`), автоматическая фильтрация клиентов и привязка сообщений.
* **Динамический расчет статусов:** Статус рассылки (`Создана`, `Запущена`, `Завершена`) рассчитывается на лету на основе системного времени при каждом просмотре объекта.
* **Отправка по расписанию и требованию:** Интегрирован фоновый планировщик задач `APScheduler` для проверки и рассылки писем каждые 5 минут. Реализована кнопка ручного принудительного запуска из интерфейса.
* **Логирование попыток:** Каждая отправка фиксируется в модели `Log` с сохранением даты, статуса (`Успешно`/`Не успешно`) и ответа сервера.

### Часть 2. Расширение функциональности
* **Авторизация и верификация:** Регистрация пользователей с обязательным подтверждением почтового адреса (в режиме разработки ссылка для активации генерируется в консоль). Восстановление пароля со случайным токеном.
* **Разграничение прав доступа (Роли):**
  * `Пользователь`: Полный доступ (CRUD) исключительно к своим клиентам, сообщениям и рассылкам.
  * `Менеджер`: Просмотр всех данных в системе, просмотр списка пользователей, функционал отключения чужих рассылок и принудительной блокировки нежелательных аккаунтов. Без прав на редактирование и удаление чужого контента.
* **Оптимизация производительности:** Настроено серверное кэширование Redis для счетчиков главной страницы проекта.

## 🛠 Стек технологий
* **Backend:** Python 3.12, Django 6.1 (или 6.x)
* **Database:** PostgreSQL
* **Task Queue / Scheduler:** APscheduler (`django-apscheduler`)
* **Caching:** Redis (`django-redis`)
* **Frontend:** HTML5, Bootstrap 5, JavaScript (динамическая стилизация форм)
* **Package Manager:** Poetry

## 💻 Инструкция по установке и запуску

### 1. Клонирование и подготовка окружения
Убедитесь, что у вас установлены PostgreSQL и Redis, а службы запущены.

```bash
# Перейдите в корневую папку проекта
cd mail_manager_1

# Установите зависимости проекта через Poetry
poetry install

# Активируйте виртуальное окружение
poetry shell
```

### 2. Настройка переменных окружения
Создайте в корне проекта файл **`.env`** и заполните его по следующему шаблону (кавычки использовать не нужно):

```env
SECRET_KEY=ваш_секретный_ключ_django
DB_NAME=имя_базы_данных
DB_USER=имя_пользователя_бд
DB_PASSWORD=пароль_от_бд
DB_HOST=127.0.0.1
DB_PORT=5432

# Настройки почты (В режиме локальной разработки используется EmailBackend в консоль)
EMAIL_HOST_USER=ваш_логин@yandex.ru
EMAIL_HOST_PASSWORD=пароль_приложения_яндкса
```

### 3. Применение миграций и создание суперпользователя
```bash
# Выполните миграции базы данных (включая таблицы APScheduler)
python manage.py migrate

# Создайте администратора системы
python manage.py createsuperuser
```

### 4. Запуск проекта
Для полноценной работы сервиса необходимо запустить два параллельных процесса в разных вкладках терминала PyCharm.

* **Вкладка 1: Запуск веб-сервера**
  ```bash
  python manage.py runserver
  ```
  *Проект станет доступен в браузере по адресу: http://127.0.0*

* **Вкладка 2: Запуск фонового планировщика рассылок**
  ```bash
  python manage.py run_apscheduler
  ```

## 📝 Особенности тестирования проекта разработчиком
* **Отладка почты:** Так как внешние SMTP-подключения Яндекса могут накладывать ограничения безопасности, проект переведен на безопасный отладочный бэкенд `"django.core.mail.backends.console.EmailBackend"`.
* **Подтверждение аккаунта:** При регистрации нового пользователя страница редиректит на логин, а в терминал веб-сервера (Вкладка 1) выводится текст письма. Найдите строку `==== РАБОЧАЯ ССЫЛКА ДЛЯ БРАУЗЕРА: ... ====`, зажмите `Ctrl` и кликните по ней для активации профиля.
* **Проверка рассылки:** При создании рассылки убедитесь, что дата старта и окончания соответствуют вашему текущему времени (в `settings.py` установлен часовой пояс `Europe/Moscow`). Логи отправки писем по расписанию или при нажатии кнопки «Запустить сейчас» отображаются текстом во вкладке терминала `runserver`.
